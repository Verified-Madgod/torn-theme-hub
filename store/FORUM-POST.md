**Title:** [Extension] Theme Hub for Torn – 23 colour themes (Firefox / Chrome / Edge)

---

Got tired of choosing between light and dark, so I made an extension that
gives Torn **23 colour themes** you can switch from the toolbar: Midnight,
Nord, Dracula, Tokyo Night, Catppuccin, Gruvbox, Solarized, Synthwave,
Cyberpunk, Matrix, Paper, Slate and more (18 dark, 5 light).

**Install**
- Firefox: <AMO link>
- Chrome / Brave / Opera: <Chrome Web Store link>
- Edge: <Edge Add-ons link>

**What it does**
- Re-colours Torn with the theme you pick. Click a theme, it applies instantly.
- Every theme is checked so text stays readable (minimum 3:1 contrast) in both
  Torn light and dark mode.
- Anything whose colour *means* something is left alone: money, your
  energy / nerve / happy / life bars, status banners, errors, item rarity.
- Jail / hospital / travel colours are kept by default so you can always tell
  where you are (there's a toggle if you want those themed too).
- Options to hide the page backdrop, theme the chat, and tone down images.
- Works alongside TornTools.

**Rules / safety**
This is a pure CSS re-skin and I've built it to stay well inside the scripting
rules:
- It makes **no requests of any kind**, to Torn or anywhere else. There is no
  network code in it at all.
- It only changes colours on the page you currently have open. It doesn't
  read other pages, doesn't touch game actions, and doesn't go near CAPTCHAs.
- It collects **no data**. Your theme choice is saved in your own browser and
  never leaves it.
- The source is fully readable (no minified or obfuscated code). <optional: GitHub link>

**Known limits**
Torn has a lot of pages. If you spot an area that isn't themed, or looks
wrong, reply here with the page and a screenshot (and, if you can, right-click
→ Inspect on the spot and paste the HTML) and I'll fix it in the next update.
Updates install automatically through the store.

Feedback and theme requests welcome!
