# Privacy Policy — Theme Hub for Torn

_Last updated: 18 September 2026_

**Theme Hub for Torn collects no data.** Nothing about you, your Torn account,
or your browsing is gathered, stored remotely, sold, or shared with anyone.

## What the extension stores

Your theme settings (which theme is selected, and the on/off toggles in the
popup) are saved with the browser's built-in extension storage
(`storage.local`). That storage lives only in your browser profile, and the
extension never sends it anywhere. Removing the extension deletes it.

## What the extension reads

- **Only pages on torn.com**, and only the page you have open. It sets colour
  variables and a few `data-thm` attributes on that page so the theme's CSS
  applies. It does not read, record, or transmit any game data, messages,
  or personal information shown on the page.
- **Inspect page palette** (optional button in the popup): when you click it,
  the extension lists the CSS colour variables in stylesheets that the current
  Torn page has *already loaded*, and copies that list to your clipboard. It
  contains stylesheet names and colour values only. Nothing is sent anywhere.

## Network activity

None. The extension contains no code that makes network requests: no `fetch`,
`XMLHttpRequest`, WebSocket, beacon, analytics, or remote code. It does not
request anything from torn.com or any other server.

## Permissions and why they exist

| Permission | Why |
|---|---|
| `storage` | Remember which theme you picked. |
| Access to `torn.com` | Apply the theme's CSS to Torn pages. |

## Torn's rules

The extension only restyles the page you are actively viewing. It makes no
requests, reads no other pages, and does not interact with CAPTCHAs or game
actions, consistent with Torn's rules on scripts and extensions.
